Code for my senior thesis titled "Engineering the multiphoton cluster state for one-way quantum computing in dynamically modulated qubit arrays". Aim is to design a model to calculate the ideal modulation frequency for a qudit to optimize its fidelity. The final model should be able to optimize both real and imaginary components of the frequency (resonance frequency and modulation decay rate). Aiming for a fidelity of 0.9 or higher for a three or four cluster state. Wavefunctions are calculated using a scattering matrix. Currently using a Bell state as the target state. Still need to edit input to accept Fourier coefficients.
